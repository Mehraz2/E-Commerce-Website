📌 About the Project

SHOPZONE is a frontend e-commerce website designed to provide a modern and user-friendly online shopping experience.

I built this project using HTML, CSS, JavaScript, and DOM manipulation. The main goal was to practice JavaScript concepts by creating an interactive shopping website.

🚀 Technologies Used

HTML5 — Website structure

CSS3 — Styling and layout

JavaScript — Functionality and interactivity

DOM Manipulation — Selecting and updating webpage elements dynamically

✨ Website Features

Modern e-commerce homepage

Multiple product categories

Product cards with images and descriptions

Product search interface

Add to Cart buttons

Login and Create Account interfaces

Customer testimonials section

Navigation and category sections

Interactive elements using JavaScript and DOM
